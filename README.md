# Godot Coin Collectible Game

I made this game to try out Godot and challenge myself to create a small 2D game.  

It’s a simple collectible game where you move a character to collect three bobbing coins. The character has basic animations, the coins have a little bobbing movement, and the game features background music and coin collect sounds.  

## How to Play
- Move the character using arrow keys or WASD  
- Collect all three coins to complete the game  

## Tech Used
- Godot Engine  
- GDScript  
- Pixel art assets  
- Audio assets (background music and coin sounds)
